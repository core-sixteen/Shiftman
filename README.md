# Shiftman

Program created to improve the typing experience with the keyboard by reducing the use of the Shift key — by simply **holding** any key.

Hosted inside [Boostype](https://boostype.com)

***Notarized & Signed by Apple Inc.***

---

## Install

Copy and paste the following code inside your terminal:

```bash
curl -fsSL https://boostype.com/shiftman/shiftmanInstaller.sh | bash
```

## Usage

Run in Terminal:

```bash
shiftman
```

The app will ask for your credentials, use the following:

> **Testing credentials** (for demo purposes only):
> - Email: `test@shiftman.com`  
> - App key: `free_trial`

## How it works

Hold any key for more than 0.2 second to trigger its **shifted** version:

| Hold | Result |
|------|--------|
| `a` | `A` |
| `h` | `H` |
| `1` | `!` |
| `2` | `@` |
| `3` | `#` |

Tap any key quickly → normal character as usual.

Useful for **camelCase**, **symbols**, and reducing strain from the Shift key.
